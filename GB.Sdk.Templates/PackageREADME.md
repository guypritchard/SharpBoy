# GB.Sdk.Templates

Install with `dotnet new install GB.Sdk.Templates`, then create a project using
`dotnet new gb-dmg`, `dotnet new gb-dmg-background` or `dotnet new gb-dmg-sprites`.
Each starter contains its own project, README, source, build script and (where
needed) artwork. Install `GB.Compiler.Cli` (`gbc`) and RGBDS 0.9.0 to compile
ROMs. See https://github.com/guypritchard/SharpBoy for installation details.
